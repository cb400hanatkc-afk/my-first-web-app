# 場作り（ホスティング）スキルの現在地と伸ばし方

- 作成: 2026-07-27（7/26初主催の翌日）
- 前提の確認: 「場を設計し、飛び込みやすい雰囲気を作ることが本質」という本人の見立ては**正しい**。7/26はコンテンツ（コーチング説明）を割愛したのに1時間濃密に回った＝場が会を成立させた証拠

## 絞り込み: ラジオから盗むべきは「喋る技術」ではない

オフ会主催 / ラジオパーソナリティ / ファシリテーターは必要な技術が別物。
- ラジオ = 一人で間を持たせる技術
- ファシリ = 合意形成と時間管理
- オフ会主催 = 場の安全性

混ぜて「話が上手い人」を目指すと**本人の既存の弱点（説明が長くなる）を増幅する**。7/12リハで説明が予定の倍、7/26の学びも「誰に何を伝えるか設計しないと伝わらない」。喋りが足りない側ではなく、喋りすぎを警戒すべき側。

**ラジオから盗むのは「途中から聴き始めた人がいる前提で話す設計」。** oViceの出入り自由と完全に同型で、かつ未実装の技術。

## 場作りの4ステップと現在地

**①迎える → ②約束する → ③開く → ④渡す**

| ステップ | 内容 | 現在地 |
|---|---|---|
| ①迎える | 入ってきた人の不安を最初の10秒で消す | **弱い**。7/26は自分の経歴説明から開始。聞き手が「何をしていい場か」を知らないまま主催者の話を聞く状態 |
| ②約束する | 何が起きるか/何をしなくていいか | **省略した**。全員経験者のため判断は妥当だが、1時間の地図が場に置かれなかった |
| ③開く | 自分から鎧を脱ぐ | **非常に強い**。「傾聴レベル1だった」の自己開示が場を深くした。**ただし中盤で発動** |
| ④渡す | 問いを置いて手渡す | 設計はあるが実行が挙手待ちに戻りがち |

### 最大の発見

**最強の武器（③自己開示）が、最も効く場所（冒頭）に置かれていない。**
ぐんぴいは冒頭で恥ずかしい話をする→聴き手は1分で「格好つけなくていい場所だ」と分かる。同じ弾を持っているのに30分後に撃っている。

### 改訂オープニング案（30秒・①→③→②→④）

> こんばんは、働きグマです。今、始まる前に心臓バクバクしてました。初主催なので。（③）
> この会、教える会じゃないです。私自身、半年前に『傾聴』を知らずに部下の話を聞いてたクチなので。（③）
> なので今日は、聞くだけでOK、途中で抜けてOK、カメラも自由です。（②）
> あなたが「あ、これコーチングかも」って思った瞬間があったら、それを聞かせてください。（④）

## 伸ばし方（3つだけ）

1. **冒頭3分だけを録音して聴き返す**。全部聴くと続かない。場の質は最初の3分で決まるので定点観測する
2. **好きなラジオの冒頭3分を写経する**。文字起こしして「何秒目に聴き手へ呼びかけたか」「自分の話は何秒か」を数字で見る
3. **1回1改善**。コーチングのコンピテンシー練習と同じ型を流用。次回は「①迎える」だけを宣言してジョーさんに見てもらう

## 発信（ノウハウ記事）の設計

**一般論のノウハウ記事にしない。** 「オフ会成功の5つのコツ」は世に無数にある。価値は一次体験の密度。

武器になる素材:
1. 「主催は教えられる人がやるもの」という思い込みが、バスケの一言で外れた
2. プレ開催でoViceが2回落ちた
3. 本番より16時の偶然の30分の方が届いた（集客装置は時間帯ではなく「場に居ること」）
4. 準備工数の実測（告知文・ポスター・トリセツ・進行表・台本・エピソード集）
5. **新規ゼロだったこと**。隠さず書けるかが記事の信頼度を決める
