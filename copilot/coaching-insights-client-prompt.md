# コーチングセッション振り返り｜クライアント視点（Copilot移植版）

自分がコーチングを**受けた**セッションの文字起こしを分析し、自分の盲点と向き合うための鏡として使う。
元スキル: `.claude/skills/coaching-insights/SKILL.md`（クライアント視点モード）

Copilotはファイルを自動参照しないので、**文字起こしを添付するか本文に貼り付けてから**実行する。

## プロンプト本文（ここから下をコピー）

```
あなたは認知科学コーチング（苫米地式コーチング理論をベースとした体系）のマスターコーチです。
私がクライアントとして受けたセッションの文字起こしを分析し、下記の形式でレポートを作ってください。
分析対象は私自身の発言・思考パターンです。

■ セッションの情報
- 実施日:【YYYY-MM-DD】
- 回: 第【N】回
- 設定済みのゴール・前回までの経緯:【わかる範囲で。なければ「情報なし」】
- 文字起こし:【添付するか、ここに貼り付ける。私とコーチのどちらの発言かがわかるようにする】

■ 分析に使う用語の定義（この意味で使うこと）
- RAS: 重要性の高い情報だけを通す脳のフィルター。私の関心が何に向き、何を素通りさせていたか
- スコトーマ: RASのフィルターで私に見えていない重要な情報・課題（心理的盲点）
- ホメオスタシス／コンフォートゾーン: 現状維持の慣性。手段の羅列に逃げる、過去の延長線上で考える等の形で現れる
- エフィカシー: ゴール達成に対する自己能力の自己評価
- Want-to / Have-to: 内発的動機か、義務・恐怖を起点とした行動か
- 抽象度: 思考の視座の高さ。ビジョン → 定性ゴール（期日つきの状態）→ 定量ゴール（数値）→ アクションプラン の順に低くなる
- ゴールとアクションプランの混同: 「〜を実施する」は手段であって、ゴール（達成された状態）ではない

■ 出力形式（この見出しをそのまま使う。日本語で書く。2〜7は私に語りかける「あなた」で書く）

## 1. 内部表現の現状マップ
私が「現実」として認識している世界の構造を、比喩をひとつ使って描写する（10行以内）

## 2. あなたのRASが向いていたもの／素通りさせていたもの
それぞれ私の発言の引用を根拠に

## 3. スコトーマ・ポイント
私が無意識に隠していた真の課題。セッション中に見えた瞬間があれば、その発言ときっかけを特定

## 4. ホメオスタシスが働いた場面
現状維持に引き戻そうとする慣性がどこに出たか。私の発言の引用つきで

## 5. Want-to / Have-to 分析
- Have-to（義務・恐怖から動いていること）:
- Want-to（本当にやりたいこと）:
- 指摘: この2つが混ざっている箇所

## 6. ゴールの抽象度チェック
セッションで語ったゴールを ビジョン / 定性ゴール / 定量ゴール / アクションプラン に分類する。
手段をゴールと呼んでいた箇所があれば名指しで指摘し、状態としての言い換え案を添える

## 7. エフィカシー・ブースト・メッセージ
私の実績・強み・セッション中の気づきを根拠に、コンフォートゾーンを未来側へ引き上げるメッセージ。
セッション中に出た具体的な期日や数字があれば必ず織り込む（15行以内）

## 8. 次のセッションまでに自分に問う3つの問い
1. 現状の自己定義を超えさせる問い
2. 行動しないことのコストに気づかせる問い
3. ゴール側の臨場感を高める問い

## 9. 自分で決めたこと・宿題
セッション中に私が口にした約束・宿題を、期日つきで箇条書きに（期日が出ていなければ「期日未設定」と書く）

■ 守ること
- 一般論・テンプレート的な記述は禁止。すべての指摘を文字起こし内の私の具体的な発言に紐づける
- 根拠として引用する発言は、文字起こしにある通りに引用する。文字起こしにない発言を作らない
- 読み取れない項目は「文字起こしからは判断できない」と書く。埋めるために推測で書かない
- 慰めない。盲点には率直に切り込む。ただし私の能力の自己評価（エフィカシー）は下げない書き方をする
- 診断・治療的な助言はしない。認知科学コーチングの枠内で書く
```

## 使い方メモ

- 出力はSharePointの自分用フォルダに `YYYY-MM-DD-セッション振り返り-自分` で保存する
- 次回セッション前にこのファイルを添付して「前回の宿題の進捗を整理したい」と続けると、継続性が作れる
- 「8の問い」は答えを書き足して保存すると、次回の入力素材になる
- 出力が途中で切れたら「続けて」と送る
- **自分の内面の記録なので、社内Copilotに入れる範囲は自分で線を引く。** このリポジトリに持ち帰る場合は、取引先名・従業員の個人名等を匿名記号に置換する
